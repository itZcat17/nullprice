About Nullprice

A catalogue of free tools that do the jobs paid Windows software charges for.

How these are built
Each tool is an independent implementation written from scratch. No decompilation, no borrowed code, no copied icons, names, or trade dress. Paid products are named only to describe what job the free tool does instead. This is the same footing GIMP, LibreOffice, Inkscape, and Blender stand on: functionality is not copyrightable, specific code and branding are.
Downloads are verified
Every installer is checked against a published SHA-256 checksum before it can be run. Anything that fails is deleted rather than kept, because a corrupt binary has no evidentiary value and every reason not to sit on disk where it might be executed.
Nothing leaves your machine
Nullprice fetches the catalogue and the installers you ask for. It sends no analytics, has no account system, and does not report what you install.
Prices quoted
Correct as of July 2026. A tilde means approximate. Subscription products are shown at their annual rate; everything else is a one-time licence.
